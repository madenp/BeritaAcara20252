## 1. Membuka Dashboard

### Langkah 1: Akses Dashboard
1. Buka browser (Chrome, Firefox, Safari, atau Edge)
2. Ketik URL dashboard di address bar
3. Tekan **Enter**
4. Dashboard akan loading dan menampilkan data

### Langkah 2: Tunggu Data Dimuat
- Anda akan melihat pesan **"⏳ Memuat data..."**
- Tunggu beberapa detik hingga data selesai dimuat
- Dashboard akan menampilkan statistik dan daftar mata kuliah

## 2. Memahami Tampilan Dashboard

### 📊 Bagian Header
Di bagian atas, Anda akan melihat:

```
┌─────────────────────────────────────────┐
│ 👥 Dashboard Ketua Tingkat              │
│                                         │
│ [🔍 Cari mata kuliah...]  [📋]         │
└─────────────────────────────────────────┘
```

- **Judul**: Dashboard Ketua Tingkat
- **Search Bar**: Untuk mencari mata kuliah
- **Tombol 📋**: Untuk melihat daftar ketua tingkat

### 📈 Statistik Cards
Menampilkan 3 informasi penting:

```
┌──────────┬──────────┬──────────┐
│   136    │    7     │   129    │
│  Total   │  Sudah   │  Belum   │
│  Matkul  │  Keting  │  Keting  │
└──────────┴──────────┴──────────┘
```

1. **Total Mata Kuliah**: Jumlah semua mata kuliah
2. **Sudah Ada Keting**: Mata kuliah yang sudah memiliki ketua tingkat
3. **Belum Ada Keting**: Mata kuliah yang masih kosong

### 📝 Section Mata Kuliah

#### A. Belum Ada Ketua Tingkat (Prioritas)
- **Warna**: Putih dengan border
- **Status**: "Belum ada ketua tingkat" (merah)
- **Action**: Klik untuk mendaftar
- **Icon**: 📝

#### B. Sudah Ada Ketua Tingkat
- **Warna**: Abu-abu gradient
- **Status**: Terkunci 🔒
- **Info**: Nama, NIM, No WA ketua
- **Action**: Tidak bisa diklik

## 3. Mencari Mata Kuliah

### Cara Menggunakan Search

**Langkah 1: Klik Search Bar**
```
┌─────────────────────────────────┐
│ 🔍 Cari mata kuliah...          │
└─────────────────────────────────┘
```

**Langkah 2: Ketik Kata Kunci**
Anda bisa mencari berdasarkan:
- Nama mata kuliah: `"Akuntansi"`
- Kelas: `"A"`, `"B"`, `"MBKM"`
- Nama ketua: `"John"`
- NIM: `"2021001"`

**Langkah 3: Lihat Hasil**
- Hasil akan muncul **secara real-time**
- Daftar akan ter-filter otomatis
- Jika tidak ada hasil, akan muncul pesan: **"Tidak ada hasil untuk..."**

**Langkah 4: Hapus Pencarian**
- Hapus teks di search bar
- Tekan **Backspace** atau **Delete**
- Semua mata kuliah akan muncul kembali

### Contoh Pencarian

```
Ketik: "Basis Data"
Hasil: 
  ✅ Basis Data - Kelas A
  ✅ Basis Data - Kelas B
  ✅ Basis Data - Kelas MBKM
```

## 4. Mendaftar Sebagai Ketua Tingkat Baru

### Scenario: Anda ingin mendaftar untuk mata kuliah yang belum ada ketua tingkat

### Langkah 1: Pilih Mata Kuliah
1. Scroll ke section **"📝 Belum Ada Ketua Tingkat"**
2. Cari mata kuliah yang Anda inginkan
3. **Klik card** mata kuliah tersebut

```
┌─────────────────────────────────┐
│ Akuntansi Keuangan - Kelas A    │
│                                 │
│ Status: Belum ada ketua tingkat │
│ 📝 Klik untuk mendaftar         │
└─────────────────────────────────┘
       ↓ KLIK DI SINI
```

### Langkah 2: Modal Akan Muncul
Modal dengan 2 tab akan terbuka:

```
┌─────────────────────────────────┐
│ Pilih Ketua Tingkat         × │
│ Akuntansi Keuangan - Kelas A    │
├─────────────────────────────────┤
│ [👤 Pilih yang Ada] [➕ Daftar Baru] │
└─────────────────────────────────┘
```

### Langkah 3: Klik Tab "➕ Daftar Baru"
```
┌─────────────────────────────────┐
│ [👤 Pilih yang Ada] [➕ Daftar Baru] │
│                     ^^^^^^^^^^^
│                     KLIK DI SINI
└─────────────────────────────────┘
```

### Langkah 4: Isi Form
Form dengan 3 field akan muncul:

```
┌─────────────────────────────────┐
│ Nama Lengkap *                  │
│ [_________________________]     │
│                                 │
│ NIM *                           │
│ [_________________________]     │
│                                 │
│ No WhatsApp *                   │
│ [_________________________]     │
│                                 │
│ [Batal]        [Daftar]         │
└─────────────────────────────────┘
```

**Isi dengan data Anda:**
- **Nama Lengkap**: Nama lengkap sesuai KTM
  - Contoh: `John Doe`
- **NIM**: Nomor Induk Mahasiswa
  - Contoh: `2021001`
- **No WhatsApp**: Nomor yang aktif (dengan 08 atau 62)
  - Contoh: `08123456789` atau `6281234567890`

### Langkah 5: Submit
1. Pastikan semua field terisi dengan benar
2. Klik tombol **"Daftar"** (warna ungu)
3. Loading akan muncul: **"🔄 Menyimpan data..."**
4. Tunggu hingga muncul pesan sukses

### Langkah 6: Konfirmasi Sukses
```
┌─────────────────────────────────┐
│ ✅ Data ketua tingkat berhasil  │
│    disimpan!                    │
└─────────────────────────────────┘
```

- Modal akan tertutup otomatis
- Dashboard akan reload
- Mata kuliah akan pindah ke section **"🔒 Sudah Ada Ketua Tingkat"**

## 5. Memilih Ketua Tingkat yang Sudah Ada

### Scenario: Anda sudah menjadi ketua tingkat di mata kuliah lain dan ingin mendaftar untuk mata kuliah baru

### Langkah 1: Pilih Mata Kuliah
1. Klik card mata kuliah yang **belum ada ketua tingkat**
2. Modal akan terbuka

### Langkah 2: Tab "👤 Pilih yang Ada" (Default)
Tab ini akan terbuka secara otomatis:

```
┌─────────────────────────────────┐
│ 💡 Pilih ketua tingkat yang     │
│    sudah pernah mendaftar...    │
├─────────────────────────────────┤
│ 🔍 Cari nama ketua tingkat...   │
├─────────────────────────────────┤
│ ┌─────────────────────────────┐ │
│ │ John Doe                    │ │
│ │ NIM: 2021001                │ │
│ │ No WA: 08123456789          │ │
│ │ 📚 2 mata kuliah            │ │
│ └─────────────────────────────┘ │
│                                 │
│ ┌─────────────────────────────┐ │
│ │ Jane Smith                  │ │
│ │ NIM: 2021002                │ │
│ │ No WA: 08987654321          │ │
│ │ 📚 1 mata kuliah            │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

### Langkah 3: Cari Nama Anda (Opsional)
Jika daftar panjang, gunakan search:
```
┌─────────────────────────────────┐
│ 🔍 Cari nama ketua tingkat...   │
│     [John]                      │
└─────────────────────────────────┘
```

### Langkah 4: Klik Card Nama Anda
```
┌─────────────────────────────┐
│ John Doe                    │ ← KLIK DI SINI
│ NIM: 2021001                │
│ No WA: 08123456789          │
│ 📚 2 mata kuliah            │
└─────────────────────────────┘
```

### Langkah 5: Konfirmasi Muncul
Modal konfirmasi akan muncul:

```
┌─────────────────────────────────┐
│           👤                    │
│     Pilih Ketua Tingkat         │
│                                 │
│ Pilih John Doe sebagai ketua    │
│ tingkat untuk                   │
│ Akuntansi Keuangan - Kelas A?   │
│                                 │
│ [Batal]        [Daftar]         │
└─────────────────────────────────┘
```

### Langkah 6: Klik "Daftar"
1. Klik tombol **"Daftar"** (ungu)
2. Loading muncul: **"🔄 Menyimpan data..."**
3. Tunggu proses selesai

### Langkah 7: Sukses!
```
┌─────────────────────────────────┐
│ ✅ Data ketua tingkat berhasil  │
│    disimpan!                    │
└─────────────────────────────────┘
```

**Keuntungan Pilih yang Ada:**
- ✅ Tidak perlu isi form lagi
- ✅ Data otomatis sama (Nama, NIM, WA)
- ✅ Lebih cepat (1 klik)
- ✅ Konsisten di semua mata kuliah

- Atau klik di luar modal (area gelap)

## 7. Tips & Trik

### 💡 Tips Umum

1. **Gunakan Search untuk Efisiensi**
   - Ketik nama mata kuliah langsung
   - Tidak perlu scroll panjang

2. **Pilih yang Ada untuk Konsistensi**
   - Jika sudah pernah daftar, gunakan "Pilih yang Ada"
   - Data akan sama di semua mata kuliah

3. **Cek List Ketua Tingkat**
   - Gunakan tombol 📋 untuk overview
   - Lihat berapa mata kuliah yang Anda ketuai

4. **Scroll to Top**
   - Jika sudah scroll jauh ke bawah
   - Klik tombol ⬆️ di pojok kanan bawah
   - Langsung kembali ke atas

### 📱 Tips Mobile

1. **Gunakan Portrait Mode**
   - Lebih nyaman untuk scroll
   - Stat cards tetap 3 kolom

2. **Zoom Jika Perlu**
   - Pinch to zoom jika teks terlalu kecil
   - Dashboard responsive

3. **Tombol Icon Only**
   - Di mobile, tombol "List Ketua Tingkat" hanya icon 📋
   - Tetap berfungsi sama

### ⚡ Tips Cepat

**Mendaftar Cepat (Sudah Pernah Daftar):**
```
1. Klik card mata kuliah
2. Klik nama Anda di list
3. Klik "Daftar"
4. Selesai! (3 klik)
```

**Mendaftar Baru:**
```
1. Klik card mata kuliah
2. Klik tab "Daftar Baru"
3. Isi form (Nama, NIM, WA)
4. Klik "Daftar"
5. Selesai!
```

## 8. FAQ - Pertanyaan Umum

### ❓ Pertanyaan Umum

**Q: Bagaimana jika saya salah input data?**
A: Hubungi **Staff Jurusan Akuntansi** untuk pembaruan data. Ada info message di section "Sudah Ada Ketua Tingkat".

**Q: Bisa mendaftar untuk lebih dari 1 mata kuliah?**
A: Ya! Anda bisa menjadi ketua tingkat untuk banyak mata kuliah. Gunakan fitur "Pilih yang Ada" untuk mata kuliah kedua dan seterusnya.

**Q: Kenapa mata kuliah tidak muncul di search?**
A: 
- Pastikan ejaan benar
- Coba kata kunci lebih pendek (misal: "Akuntansi" bukan "Akuntansi Keuangan Daerah")
- Refresh halaman jika perlu

**Q: Tombol "Daftar" tidak bisa diklik?**
A: Pastikan semua field terisi dengan benar (ada tanda * = wajib diisi).

**Q: Data tidak tersimpan?**
A: 
- Cek koneksi internet
- Tunggu hingga loading selesai
- Jangan tutup browser saat loading
- Jika masih error, hubungi admin

**Q: Bagaimana cara melihat mata kuliah yang saya ketuai?**
A: Klik tombol 📋 "List Ketua Tingkat", cari nama Anda, lalu klik card Anda untuk expand.

**Q: Bisa membatalkan pendaftaran?**
A: Tidak bisa dari dashboard. Hubungi **Staff Jurusan Akuntansi** untuk pembatalan.

**Q: Format nomor WhatsApp yang benar?**
A: 
- ✅ `08123456789` (dengan 08)
- ✅ `6281234567890` (dengan 62)
- ❌ `+62 812-3456-789` (jangan pakai spasi/dash)

**Q: Kenapa ada mata kuliah yang terkunci 🔒?**
A: Mata kuliah tersebut sudah memiliki ketua tingkat. Anda tidak bisa mendaftar lagi.

**Q: Scroll to Top button tidak muncul?**
A: Button hanya muncul setelah Anda scroll lebih dari 300px ke bawah. Scroll sedikit lagi.
